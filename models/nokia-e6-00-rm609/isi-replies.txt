# PN_PHONE_INFO 0x0B/0x0C: EInfoServer (channel 11) reads the phone's product name from the modem
# (docs/devices/nokia-n95-8gb-rm320/n95-isc-isi-protocol-2.md 3.5). EInfoServer sends it synchronously,
# with no timeout, so until this reply existed the "Device manager" app (NSmlDMSync.exe, the *#0000#
# software-version dialog) hung on a black window forever: the app -> EInfoServer M:2 -> 1B 0B, no answer.
# Reply = cause OK, subblock id 'N' (0x4E = product name; request data 00 02), length 6, the type code.
# The 2026-11-13 run on the N8 Delight: EInfoServer got 1B 0C and the dialog opened.
reply 1B 0B 0C 00 01 4E 0C 00 06 52 4D 2D 35 39 36 00 00   # "RM-596" (on: N8 Delight, *#0000# dialog 2026-11-13)
